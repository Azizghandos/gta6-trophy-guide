Leonida Trophy Guide: the best guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. An offline web app with a localStorage-saved checklist, search and filters, a spoiler-free mode, export/import of progress, and a 5-stage platinum roadmap — every trophy with its official name, description and grade, plus an original step-by-step guide with cited sources.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network needed; the app runs entirely from its own static files.
